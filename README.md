# Transcript Search

It's a pretty shrimple YouTube caption fetcher/searcher... wanted to avoid using youtubes annoying ass api so uses yt-dlp to pull transcript and do a lot of random shtuff

input can be a single video, playlist, list of videos (untested) or entire channel (also untested)

- **Creator-submitted captions are preferred** over autogenerated youtube ones when possible, but only within your configured preferred language- in order: manual (pref) > autogen (pref) > manual (other lang) > auto (other)
- Full text search is mostly supported
- Re-fetch any video/playlist or channel to check for new videos or if something somehow failed lol

## Usage

- yt-dlp is downloaded on first run and update-checked occasionally
- Cookies are optional but recommended because youtube loves being annoyingly aggressive with their bot protections.
  - See [the yt-dlp FAQ](https://github.com/yt-dlp/yt-dlp/wiki/FAQ#how-do-i-pass-cookies-to-yt-dlp) for how to get this file.
  - If you use any program that already keeps a youtube_cookies.txt or equivalent file, you can point it at that same file. (e.g. VRCVideoCacher)

Grab the [latest release](../../releases) for Windows, macOS (Intel + Apple Silicon)
or Linux x64 (every commit will have a artifact + pre-release). no installer, its all in one executable.

- macOS: it's unsigned, so run `xattr -dr com.apple.quarantine "Transcript Search.app"`
  after unpacking or Gatekeeper won't let it open (typical mapple behavior)
- Linux: you need GTK 3 + WebKit2GTK 4.0

## Build from source

- **Python 3.10+**
- **Deno 2.0+**

1. Install Python dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Build the UI:
   ```
   deno task build
   ```

3. Run the app:
   ```
   python app.py
   ```

Set `TRANSCRIPT_SEARCH_YTDLP` to point at an existing yt-dlp binary if you don't
want the app managing its own copy.

The database and yt-dlp live in `data/` next to the exe on Windows (so it stays
portable), `~/Library/Application Support/Transcript Search` on macOS and
`~/.local/share/transcript-search` on Linux. 

Set `CAPTION_SEARCH_DATA_DIR` to use your own dir
